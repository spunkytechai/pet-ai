## Commercial training corpus

The production learning corpus should primarily use recordings collected through PET AI with explicit, purpose-specific consent and documented rights.

Every corpus item should retain:

- source
- owner/rights basis
- consent status
- license
- species
- breed where known
- context
- recording conditions
- annotation provenance
- preprocessing version
- dataset version
- permitted uses

No dataset should enter production training merely because it is publicly downloadable.
