# Security Policy

## Reporting a vulnerability

Do not disclose vulnerabilities, exploit details, credentials, private recordings, or user data in public issues.

If private vulnerability reporting is available, use **Security → Report a vulnerability** on this repository. Otherwise, contact the maintainer through the GitHub profile and request a private disclosure channel.

Please include the affected version or commit, impact, reproduction steps, and mitigation ideas. Redact personal data and secrets.

## Privacy and security expectations

- Never commit credentials, service-role keys, or production environment files.
- Keep audio storage private and enforce owner-scoped access on the server and storage layer.
- Treat uploaded audio and metadata as untrusted input.
- Avoid logging raw audio, private prompts, access tokens, or personally identifiable information.
- Communicate uncertainty. PET AI is not a veterinary diagnostic tool and must not claim literal animal-language translation.
